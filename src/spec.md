# Specification

## Summary
**Goal:** Create a Savage Elite gaming team application with signup form, merch shop, shopping cart, and admin management interface.

**Planned changes:**
- Build team signup form collecting gamer tag, email, preferred game role, and experience level
- Create merch shop displaying Savage Elite branded products with images, names, descriptions, and prices
- Implement shopping cart functionality with add/remove items and quantity adjustment
- Add admin interface to view and manage team member signup applications
- Design bold gaming-focused UI with dark theme, aggressive colors (blacks, reds, neon accents), and edgy typography
- Display Savage Elite logo and merch product images from frontend/public/assets/generated

**User-visible outcome:** Users can sign up for the Savage Elite gaming team, browse and add merch products to their cart, and admins can review team applications through a dedicated management interface.
